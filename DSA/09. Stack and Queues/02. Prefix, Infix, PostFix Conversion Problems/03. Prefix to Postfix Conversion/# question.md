# Prefix to Postfix Conversion

**Difficulty**: Medium

## Problem Statement

Given a valid **Prefix** expression `s`, convert it directly to a **Postfix** expression.

## Examples

### Example 1:
```
Input: s = "*+AB-CD"
Output: "AB+CD-*"
```

## Constraints

- `1 <= s.length <= 10^5`
