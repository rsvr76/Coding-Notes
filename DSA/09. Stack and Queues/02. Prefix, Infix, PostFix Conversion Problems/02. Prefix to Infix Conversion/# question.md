# Prefix to Infix Conversion

**Difficulty**: Medium

## Problem Statement

Given a valid **Prefix** expression `s`, convert it into an equivalent **Infix** expression.

## Examples

### Example 1:
```
Input: s = "*+AB-CD"
Output: "((A+B)*(C-D))"
```

## Constraints

- `1 <= s.length <= 10^5`
