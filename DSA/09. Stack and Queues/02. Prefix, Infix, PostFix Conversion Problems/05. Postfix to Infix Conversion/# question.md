# Postfix to Infix Conversion

**Difficulty**: Medium

## Problem Statement

Given a valid **Postfix** expression `s`, convert it into an equivalent **Infix** expression.

## Examples

### Example 1:
```
Input: s = "ab*c+"
Output: "((a*b)+c)"
```

## Constraints

- `1 <= s.length <= 10^5`
