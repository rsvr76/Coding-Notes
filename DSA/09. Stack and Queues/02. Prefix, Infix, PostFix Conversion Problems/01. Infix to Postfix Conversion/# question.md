# Infix to Postfix Conversion

**Difficulty**: Medium

## Problem Statement

Given an infix expression `s` consisting of operands, operators, and parentheses, convert the infix expression to a **Postfix** expression.

## Examples

### Example 1:
```
Input: s = "a+b*(c^d-e)^(f+g*h)-i"
Output: "abcd^e-fgh*+^*+i-"
```

## Constraints

- `1 <= s.length <= 10^5`
