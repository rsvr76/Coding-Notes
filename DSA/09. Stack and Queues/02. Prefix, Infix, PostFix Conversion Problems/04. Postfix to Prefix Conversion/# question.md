# Postfix to Prefix Conversion

**Difficulty**: Medium

## Problem Statement

Given a valid **Postfix** expression `s`, convert it directly into a **Prefix** expression.

## Examples

### Example 1:
```
Input: s = "AB+CD-*"
Output: "*+AB-CD"
```

## Constraints

- `1 <= s.length <= 10^5`
