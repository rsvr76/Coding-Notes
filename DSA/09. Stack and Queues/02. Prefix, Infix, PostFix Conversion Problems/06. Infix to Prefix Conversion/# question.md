# Infix to Prefix Conversion

**Difficulty**: Medium

## Problem Statement

Given an infix expression `s`, convert it to a **Prefix** expression.

## Examples

### Example 1:
```
Input: s = "(A+B)*C"
Output: "*+ABC"
```

## Constraints

- `1 <= s.length <= 10^5`
