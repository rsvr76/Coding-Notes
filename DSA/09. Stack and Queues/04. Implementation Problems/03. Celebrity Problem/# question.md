# The Celebrity Problem

**Difficulty**: Medium

## Problem Statement

In a party of `N` people, a celebrity is a person who is known by everyone, but does not know anyone. Given an `N x N` binary matrix `M`, find the celebrity index (0-indexed) or return `-1` if no celebrity exists.

## Examples

### Example 1:
```
Input: M = [[0, 1, 0], [0, 0, 0], [0, 1, 0]]
Output: 1
Explanation: Person 1 is known by 0 and 2, but 1 knows no one.
```

## Constraints

- `2 <= N <= 3000`
