# M-Coloring Problem

**Difficulty**: Hard

## Problem Statement

Given an undirected graph with `V` vertices and `m` colors, determine if the graph can be colored using at most `m` colors such that no two adjacent vertices have the same color.

## Examples

### Example 1:
```
Input: V = 4, m = 3, edges = [[0,1],[1,2],[2,3],[3,0],[0,2]]
Output: true
```

## Constraints

- `1 <= V <= 20`
- `1 <= m <= V`
