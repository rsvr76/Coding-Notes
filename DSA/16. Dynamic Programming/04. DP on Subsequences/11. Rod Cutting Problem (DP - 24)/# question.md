# DP on Subsequences

**Difficulty**: Medium

## Problem Statement

Solve the Dynamic Programming problem **DP on Subsequences** using optimal state transitions (recursion with memoization or iterative tabular DP).

## Examples

### Example 1:
```
Input: Standard DP array / target values.
Output: Optimal value / count of valid configurations.
```

## Constraints

- `1 <= N <= 10^4`
