# Introduction to Dynamic Programming

**Difficulty**: Easy

## Problem Statement

Understand the fundamentals of Dynamic Programming (Memoization / Top-Down vs Tabulation / Bottom-Up).

Solve the `N`-th Fibonacci number problem using Memoization and Tabulation to reduce time complexity from $O(2^N)$ to $O(N)$.

## Examples

### Example 1:

```
Input: n = 5
Output: 5
Explanation: 0, 1, 1, 2, 3, 5.
```

## Constraints

- `0 <= n <= 1000`
