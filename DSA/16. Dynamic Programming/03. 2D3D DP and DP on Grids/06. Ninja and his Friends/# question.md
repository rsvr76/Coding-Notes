# 2D3D DP and DP on Grids

**Difficulty**: Medium

## Problem Statement

Solve the Dynamic Programming problem **2D3D DP and DP on Grids** using optimal state transitions (recursion with memoization or iterative tabular DP).

## Examples

### Example 1:
```
Input: Standard DP array / target values.
Output: Optimal value / count of valid configurations.
```

## Constraints

- `1 <= N <= 10^4`
