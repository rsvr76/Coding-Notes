# Introduction to Bit Manipulation and Bit Tricks

**Difficulty**: Easy

## Problem Statement

Learn essential bitwise operations (`AND &`, `OR |`, `XOR ^`, `NOT ~`, Left Shift `<<`, Right Shift `>>`).

Given an integer `n` and an index `i`, perform:
1. Check if the `i`-th bit is set.
2. Set the `i`-th bit.
3. Clear/Unset the `i`-th bit.

## Examples

### Example 1:

```
Input: n = 13 (1101 in binary), i = 2
Output:
Is Set: true
Set Bit: 13
Clear Bit: 9 (1001 in binary)
```

## Constraints

- `0 <= n <= 10^9`
- `0 <= i <= 31`
