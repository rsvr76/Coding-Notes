# Find All Divisors of a Number

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, find and print all divisors of `N` in sorted order.

## Examples

### Example 1:
```
Input: N = 36
Output: [1, 2, 3, 4, 6, 9, 12, 18, 36]
```

## Constraints

- `1 <= N <= 10^9`
