# Prime Factorization Using Sieve

**Difficulty**: Medium

## Problem Statement

Given an integer `N` and multiple queries, compute the prime factorization of each number in $O(\log N)$ time using Smallest Prime Factor (SPF) array created by Sieve.

## Examples

### Example 1:
```
Input: N = 1224
Output: [2, 2, 2, 3, 3, 17]
```

## Constraints

- `2 <= N <= 10^6`
