# Print All Prime Factors of a Number

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, find and print all its prime factors in ascending order.

## Examples

### Example 1:
```
Input: N = 60
Output: [2, 3, 5]
```

## Constraints

- `2 <= N <= 10^9`
