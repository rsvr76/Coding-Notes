# Problems on BFSDFS

**Difficulty**: Medium

## Problem Statement

Given a Graph with $V$ vertices and $E$ edges, compute the solution for **Problems on BFSDFS** using optimal graph search techniques.

## Examples

### Example 1:
```
Input: V = 5, E = 4, adjacency list representation.
Output: Graph traversal path / shortest distances array.
```

## Constraints

- `1 <= V <= 10^4`
- `0 <= E <= 10^5`
