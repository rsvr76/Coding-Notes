# Topological Sort / Kahn's Algorithm

**Difficulty**: Medium

## Problem Statement

Given a Directed Acyclic Graph (DAG) with `V` vertices, return a valid **Topological Sort** ordering using Kahn's BFS-based algorithm.

## Examples

### Example 1:
```
Input: V = 6, edges = [[5, 2], [5, 0], [4, 0], [4, 1], [2, 3], [3, 1]]
Output: [5, 4, 2, 3, 1, 0]
```

## Constraints

- `1 <= V <= 10^4`
