# DFS Traversal of Graph

**Difficulty**: Easy

## Problem Statement

Given a connected undirected graph with `V` vertices starting from vertex 0, return a list containing the **Depth First Search (DFS)** traversal.

## Examples

### Example 1:
```
Input: V = 5, adj = [[1, 2], [0, 3, 4], [0], [1], [1]]
Output: [0, 1, 3, 4, 2]
```

## Constraints

- `1 <= V <= 10^4`
