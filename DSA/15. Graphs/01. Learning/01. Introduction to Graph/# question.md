# Introduction to Graph Types and Definitions

**Difficulty**: Easy

## Problem Statement

Given number of vertices `V` and edges `E` of an undirected graph, calculate total degrees, max possible edges, and component properties.

## Examples

### Example 1:
```
Input: V = 5, E = 6
Output: Total Degree = 12 (2 * E)
```

## Constraints

- `1 <= V <= 10^5`
