# BFS Traversal of Graph

**Difficulty**: Easy

## Problem Statement

Given a connected undirected graph with `V` vertices starting from vertex 0, return a list containing the **Breadth First Search (BFS)** traversal.

## Examples

### Example 1:
```
Input: V = 5, adj = [[1, 2, 3], [0], [0, 4], [0], [2]]
Output: [0, 1, 2, 3, 4]
```

## Constraints

- `1 <= V <= 10^4`
