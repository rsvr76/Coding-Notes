# Connected Components in an Undirected Graph

**Difficulty**: Easy

## Problem Statement

Given an undirected graph with `V` vertices, find the total number of connected components in the graph.

## Examples

### Example 1:
```
Input: V = 5, edges = [[0, 1], [1, 2], [3, 4]]
Output: 2
```

## Constraints

- `1 <= V <= 10^5`
