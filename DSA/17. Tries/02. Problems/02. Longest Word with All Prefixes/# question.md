# Longest Word With All Prefixes (Complete String)

**Difficulty**: Medium

## Problem Statement

Given an array of strings `words`, find the longest string such that **every prefix** of that string is also present in `words`. If multiple exist, return lexicographically smallest.

## Examples

### Example 1:
```
Input: words = ["n", "ni", "nin", "ninja", "ninj"]
Output: "ninja"
```

## Constraints

- `1 <= words.length <= 10^5`
