# Reverse Words in a String / Palindrome Check

**Difficulty**: Easy

## Problem Statement

Given a string `s`, reverse the order of words in `s` and check if the resulting string or individual words satisfy palindromic properties.

## Examples

### Example 1:
```
Input: s = "the sky is blue"
Output: "blue is sky the"
```

### Example 2:
```
Input: s = "  hello world  "
Output: "world hello"
```

## Constraints

- `1 <= s.length <= 10^4`
- `s` contains English letters, digits, and spaces.
