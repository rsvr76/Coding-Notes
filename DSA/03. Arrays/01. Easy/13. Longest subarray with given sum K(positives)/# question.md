# Longest Subarray with Sum K (Positive Elements)

## Problem Statement

Given an array of positive integers and a target sum `K`, find the length of the longest subarray with sum equal to `K`.

## Input

Array `arr` of positive integers, integer `K`.

## Output

Length of longest subarray.

## Examples

### Example 1

**Input**:
```
arr = [1, 2, 3, 1, 1, 1, 1], K = 3
```
**Output**:
```
3
```
**Explanation**: Subarray [1, 1, 1] has length 3 and sum 3.

## Constraints

- 1 <= N <= 10^5
- 1 <= arr[i], K <= 10^9

## Expected Complexity

Time: O(N)
Space: O(1)
