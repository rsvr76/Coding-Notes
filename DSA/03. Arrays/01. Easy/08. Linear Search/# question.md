# Linear Search Algorithm

## Problem Statement

Given an array `arr` of `N` integers and an integer `num`, return the index of first occurrence of `num`. If not present, return `-1`.

## Input

Array `arr`, integer `N`, integer `num`.

## Output

First zero-based index of `num` or `-1`.

## Examples

### Example 1

**Input**:
```
arr = [1, 2, 3, 4, 5], num = 4
```
**Output**:
```
3
```
**Explanation**: 4 is present at index 3.

## Constraints

- 1 <= N <= 10^5

## Expected Complexity

Time: O(N)
Space: O(1)
