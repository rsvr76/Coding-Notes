# Find Missing Number in Array

## Problem Statement

Given an array of `N-1` distinct integers in range `1` to `N`, find the missing number.

## Input

An array `arr` of size `N-1`.

## Output

The missing integer.

## Examples

### Example 1

**Input**:
```
N = 5, arr = [1, 2, 4, 5]
```
**Output**:
```
3
```
**Explanation**: 3 is missing from 1..5.

## Constraints

- 1 <= N <= 10^5

## Expected Complexity

Time: O(N)
Space: O(1)
