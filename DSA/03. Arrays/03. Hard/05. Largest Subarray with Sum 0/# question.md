# Length of Largest Subarray with Sum 0

## Problem Statement

Given an array `arr` of `N` integers, find the length of the longest subarray with sum equal to `0`.

## Input

An array `arr` of `N` integers.

## Output

Length of longest subarray with sum 0.

## Examples

### Example 1

**Input**:
```
arr = [15, -2, 2, -8, 1, 7, 10, 23]
```
**Output**:
```
5
```
**Explanation**: [-2, 2, -8, 1, 7] has sum 0 and length 5.

## Constraints

- 1 <= N <= 10^5

## Expected Complexity

Time: O(N)
Space: O(N)
