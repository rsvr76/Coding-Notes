# Pattern 5: Inverted Right Pyramid

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print an inverted right-angled triangle of stars from `N` stars down to `1` star.

## Input

An integer `N`.

## Output

Print `N` rows of stars in decreasing order.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
* * * *
* * *
* *
*
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
