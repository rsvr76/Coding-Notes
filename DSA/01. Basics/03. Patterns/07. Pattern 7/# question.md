# Pattern 7: Star Pyramid

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a centered pyramid of stars with `N` rows.

## Input

An integer `N`.

## Output

Print `N` rows of stars centered with spaces.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
   *
  ***
 *****
*******
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
