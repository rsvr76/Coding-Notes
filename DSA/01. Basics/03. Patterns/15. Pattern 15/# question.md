# Pattern 15: Reverse Letter Triangle

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print an inverted right-angled triangle with uppercase letters from `'A'` up to `'A' + N - i`.

## Input

An integer `N`.

## Output

Print `N` rows of letters in decreasing row lengths.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
A B C D
A B C
A B
A
```

## Constraints

- `1 <= N <= 26`

## Expected Complexity

Time: O(N^2)
Space: O(1)
