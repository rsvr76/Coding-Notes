# Pattern 18: Alpha-Triangle Pattern

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a right-angled triangle of letters starting from the `N`-th letter down to the `(N-i+1)`-th letter.

## Input

An integer `N`.

## Output

Print `N` rows of letters.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
D
C D
B C D
A B C D
```

## Constraints

- `1 <= N <= 26`

## Expected Complexity

Time: O(N^2)
Space: O(1)
