# Pattern 20: Symmetric Butterfly Pattern

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a symmetric butterfly pattern of stars.

## Input

An integer `N`.

## Output

Print `2*N - 1` rows forming a butterfly shape.

## Examples

### Example 1

**Input**: `N = 3`  
**Output**:
```
*    *
**  **
******
**  **
*    *
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
