# Pattern 8: Inverted Star Pyramid

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print an inverted centered pyramid of stars with `N` rows.

## Input

An integer `N`.

## Output

Print `N` rows of centered inverted stars.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
*******
 *****
  ***
   *
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
