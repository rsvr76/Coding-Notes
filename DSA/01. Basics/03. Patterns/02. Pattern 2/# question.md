# Pattern 2: Right-Angled Triangle Pattern

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a right-angled triangle pattern of stars (`*`) where row `i` contains `i` stars.

## Input

An integer `N`.

## Output

Print `N` rows of stars forming a right-angled triangle.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
*
* *
* * *
* * * *
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
