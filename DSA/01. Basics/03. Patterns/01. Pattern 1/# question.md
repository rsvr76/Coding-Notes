# Pattern 1: Rectangular Star Pattern

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print an `N x N` square matrix of stars (`*`).

## Input

An integer `N`.

## Output

Print `N` rows, each containing `N` stars separated by spaces.

## Examples

### Example 1

**Input**: `N = 3`  
**Output**:
```
* * *
* * *
* * *
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
