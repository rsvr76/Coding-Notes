# Pattern 4: Right-Angled Number Pyramid - II

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a right-angled triangle where row `i` contains the number `i` repeated `i` times.

## Input

An integer `N`.

## Output

Print `N` rows of repeated numbers.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
1
2 2
3 3 3
4 4 4 4
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
