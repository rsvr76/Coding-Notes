# Pattern 14: Increasing Letter Triangle

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a right-angled triangle with uppercase letters starting from `'A'` up to `'A' + i - 1` on row `i`.

## Input

An integer `N`.

## Output

Print `N` rows of uppercase letters.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
A
A B
A B C
A B C D
```

## Constraints

- `1 <= N <= 26`

## Expected Complexity

Time: O(N^2)
Space: O(1)
