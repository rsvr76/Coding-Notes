# Pattern 10: Half Diamond Star Pattern

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a right-pointing half-diamond star pattern.

## Input

An integer `N`.

## Output

Print `2*N - 1` rows of stars.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
*
**
***
****
***
**
*
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
