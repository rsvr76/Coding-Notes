# Pattern 17: Alpha-Hill Pattern

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a centered pyramid pattern of letters.

## Input

An integer `N`.

## Output

Print `N` rows forming an alphabetical hill.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
   A
  ABA
 ABCBA
ABCDCBA
```

## Constraints

- `1 <= N <= 26`

## Expected Complexity

Time: O(N^2)
Space: O(1)
