# Pattern 9: Diamond Star Pattern

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a diamond pattern of stars combining a star pyramid and an inverted star pyramid.

## Input

An integer `N`.

## Output

Print `2*N` rows forming a diamond star pattern.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
   *
  ***
 *****
*******
*******
 *****
  ***
   *
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
