# Pattern 11: Binary Number Triangle

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a right-angled triangle pattern of alternating `1`s and `0`s.

## Input

An integer `N`.

## Output

Print `N` rows of alternating binary digits.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
1
0 1
1 0 1
0 1 0 1
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
