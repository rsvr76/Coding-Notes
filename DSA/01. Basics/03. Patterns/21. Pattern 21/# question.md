# Pattern 21: Hollow Rectangle Pattern

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a hollow `N x N` square matrix of stars (`*`).

## Input

An integer `N`.

## Output

Print `N` rows forming a hollow square.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
****
*  *
*  *
****
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
