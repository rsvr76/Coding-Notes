# Pattern 12: Number Crown Pattern

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a crown pattern of numbers with symmetric numbers separated by spaces.

## Input

An integer `N`.

## Output

Print `N` rows of symmetric number patterns.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
1      1
12    21
123  321
12344321
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
