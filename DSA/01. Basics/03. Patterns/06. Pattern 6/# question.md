# Pattern 6: Inverted Numbered Right Pyramid

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print an inverted right-angled triangle with numbers from `1` to `N-i+1` on row `i`.

## Input

An integer `N`.

## Output

Print `N` rows of numbers in decreasing length.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
1 2 3 4
1 2 3
1 2
1
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
