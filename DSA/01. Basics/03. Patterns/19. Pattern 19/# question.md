# Pattern 19: Symmetric Void Pattern

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a symmetric void pattern with a diamond-shaped hollow region in the center.

## Input

An integer `N`.

## Output

Print `2*N` rows forming a symmetric void pattern.

## Examples

### Example 1

**Input**: `N = 3`  
**Output**:
```
******
**  **
*    *
*    *
**  **
******
```

## Constraints

- `1 <= N <= 20`

## Expected Complexity

Time: O(N^2)
Space: O(1)
