# Pattern 16: Alpha-Ramp Pattern

**Difficulty**: Easy

## Problem Statement

Given an integer `N`, print a right-angled triangle where row `i` contains the `i`-th uppercase letter repeated `i` times.

## Input

An integer `N`.

## Output

Print `N` rows of repeated letters.

## Examples

### Example 1

**Input**: `N = 4`  
**Output**:
```
A
B B
C C C
D D D D
```

## Constraints

- `1 <= N <= 26`

## Expected Complexity

Time: O(N^2)
Space: O(1)
