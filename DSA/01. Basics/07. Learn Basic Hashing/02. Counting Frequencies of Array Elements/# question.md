# Counting Frequencies of Array Elements

**Difficulty**: Easy

## Problem Statement

Given an array of `n` integers, count the frequency of each distinct element present in the array.

Print each element along with its frequency.

## Examples

### Example 1:

```
Input: arr = [10, 5, 10, 15, 10, 5]
Output:
10: 3
5: 2
15: 1
```

### Example 2:

```
Input: arr = [2, 2, 3, 4, 4, 2]
Output:
2: 3
3: 1
4: 2
```

## Constraints

- `1 <= n <= 10^5`
- `1 <= arr[i] <= 10^9`
