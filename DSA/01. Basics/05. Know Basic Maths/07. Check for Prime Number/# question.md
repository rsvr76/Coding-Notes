# Check for Prime Number

**Difficulty**: Easy

## Problem Statement

Given an integer `n`, check whether it is a **prime number** or not.

A prime number is a natural number greater than `1` that has no positive divisors other than `1` and itself.

## Examples

### Example 1:

```
Input: n = 11
Output: true
Explanation: 11 has only two divisors: 1 and 11.
```

### Example 2:

```
Input: n = 6
Output: false
Explanation: 6 is divisible by 1, 2, 3, and 6.
```

## Constraints

- `1 <= n <= 10^9`
