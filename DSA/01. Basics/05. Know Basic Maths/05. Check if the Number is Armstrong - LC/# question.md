# Armstrong Number

**LeetCode #1134** | **Difficulty**: Easy

## Problem Statement

Given an integer `n`, return `true` *if and only if it is an **Armstrong number***.

The `k`-digit number `n` is an Armstrong number if and only if the sum of its digits raised to the `k`-th power equals `n`.

## Examples

### Example 1:

```
Input: n = 153
Output: true
Explanation: 153 is a 3-digit number, and 153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153.
```

### Example 2:

```
Input: n = 123
Output: false
Explanation: 123 is a 3-digit number, and 123 != 1^3 + 2^3 + 3^3 = 1 + 8 + 27 = 36.
```

## Constraints

- `1 <= n <= 10^8`
