# Count Digits That Evenly Divide N

## Problem Statement

Given a number `N`, count the number of digits in `N` that evenly divide `N` (i.e. `N % digit == 0`).

## Input

An integer `N`.

## Output

An integer count.

## Examples

### Example 1

**Input**:
```
N = 12
```
**Output**:
```
2
```
**Explanation**: 1 and 2 both divide 12 evenly.

## Constraints

- 1 <= N <= 10^9

## Expected Complexity

Time: O(log10 N)
Space: O(1)
