# Print all Divisors of a Number

## Problem Statement

Given an integer `N`, find and return all factors/divisors of `N` in sorted order.

## Input

An integer `N`.

## Output

Array of integers in sorted order.

## Examples

### Example 1

**Input**:
```
N = 36
```
**Output**:
```
[1, 2, 3, 4, 6, 9, 12, 18, 36]
```
**Explanation**: Divisors of 36.

## Constraints

- 1 <= N <= 10^9

## Expected Complexity

Time: O(sqrt(N))
Space: O(number of divisors)
