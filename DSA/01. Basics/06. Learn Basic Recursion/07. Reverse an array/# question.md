# Reverse an Array Using Recursion

**Difficulty**: Easy

## Problem Statement

Given an array of `n` elements, reverse the array in-place using **recursion**.

Return the reversed array.

## Examples

### Example 1:

```
Input: n = 5, arr = [1, 2, 3, 4, 5]
Output: [5, 4, 3, 2, 1]
```

### Example 2:

```
Input: n = 4, arr = [10, 20, 30, 40]
Output: [40, 30, 20, 10]
```

## Constraints

- `1 <= n <= 10^5`
- `-10^9 <= arr[i] <= 10^9`
