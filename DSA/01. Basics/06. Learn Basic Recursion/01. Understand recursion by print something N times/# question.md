# Understand Recursion by Printing Something N Times

**Difficulty**: Easy

## Problem Statement

Given an integer `n`, print the message `"Coding Ninjas"` (or any given string) `n` times using **recursion**.

Do not use loops (`for`, `while`).

## Examples

### Example 1:

```
Input: n = 4
Output:
Coding Ninjas
Coding Ninjas
Coding Ninjas
Coding Ninjas
```

## Constraints

- `1 <= n <= 1000`
