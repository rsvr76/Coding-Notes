# Print Name N Times Using Recursion

**Difficulty**: Easy

## Problem Statement

Given an integer `n` and a string `name`, print `name` `n` times using **recursion**.

Do not use loops.

## Examples

### Example 1:

```
Input: n = 3, name = "Striver"
Output:
Striver
Striver
Striver
```

## Constraints

- `1 <= n <= 1000`
