# Print N to 1 Using Recursion

**Difficulty**: Easy

## Problem Statement

Given an integer `n`, print numbers from `n` down to `1` in decreasing order using **recursion**.

Print each number on a new line or separated by a space.

## Examples

### Example 1:

```
Input: n = 5
Output: 5 4 3 2 1
```

## Constraints

- `1 <= n <= 1000`
