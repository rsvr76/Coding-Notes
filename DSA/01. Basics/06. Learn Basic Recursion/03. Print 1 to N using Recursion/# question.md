# Print 1 to N Using Recursion

**Difficulty**: Easy

## Problem Statement

Given an integer `n`, print numbers from `1` to `n` in increasing order using **recursion**.

Print each number on a new line or separated by a space.

## Examples

### Example 1:

```
Input: n = 5
Output: 1 2 3 4 5
```

## Constraints

- `1 <= n <= 1000`
