# Factorial of a Given Number

**Difficulty**: Easy

## Problem Statement

Given an integer `n`, calculate the factorial of `n` (`n! = n * (n - 1) * ... * 1`) using **recursion**.

Return `n!`.

## Examples

### Example 1:

```
Input: n = 5
Output: 120
Explanation: 5! = 5 * 4 * 3 * 2 * 1 = 120.
```

### Example 2:

```
Input: n = 3
Output: 6
```

## Constraints

- `0 <= n <= 20`
