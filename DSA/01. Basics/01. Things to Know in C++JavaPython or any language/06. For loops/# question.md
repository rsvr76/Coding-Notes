# N-th Fibonacci Number using Loops

## Problem Statement

Given an integer `N`, find the `N`-th Fibonacci number where `F(1) = 1`, `F(2) = 1`, and `F(n) = F(n-1) + F(n-2)`.

## Input

An integer `N`.

## Output

The `N`-th Fibonacci number.

## Examples

### Example 1

**Input**:
```
N = 6
```
**Output**:
```
8
```
**Explanation**: Fibonacci sequence: 1, 1, 2, 3, 5, 8.

## Constraints

- 1 <= N <= 10000

## Expected Complexity

Time: O(N)
Space: O(1)
