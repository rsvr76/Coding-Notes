# Pass by Value and Pass by Reference

## Problem Statement

Given two integers `a` and `b`, pass them by value to add 1 and pass by reference to add 2. Return resulting values.

## Input

Two integers `a` and `b`.

## Output

Print or return updated values.

## Examples

### Example 1

**Input**:
```
a = 2, b = 3
```
**Output**:
```
3 5
```
**Explanation**: Pass by value increments to 3, pass by reference increments to 5.

## Constraints

- -10^5 <= a, b <= 10^5

## Expected Complexity

Time: O(1)
Space: O(1)
