# If Else Decision Making

## Problem Statement

Given two numbers `m` and `n`, compare them using if-else statements and return 'smaller', 'greater', or 'equal'.

## Input

Two integers `m` and `n`.

## Output

Return `smaller` if m < n, `greater` if m > n, and `equal` if m == n.

## Examples

### Example 1

**Input**:
```
m = 5, n = 3
```
**Output**:
```
greater
```
**Explanation**: 5 is greater than 3.

## Constraints

- -10^9 <= m, n <= 10^9

## Expected Complexity

Time: O(1)
Space: O(1)
