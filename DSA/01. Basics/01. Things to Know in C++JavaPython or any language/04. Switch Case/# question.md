# Switch Case Statement

## Problem Statement

Given a choice `ch` and array of dimensions `a`, calculate area of circle if `ch = 1` (a[0] is radius) or rectangle if `ch = 2` (a[0] is length, a[1] is breadth).

## Input

An integer `ch` and array `a`.

## Output

A double representing the calculated area.

## Examples

### Example 1

**Input**:
```
ch = 1, a = [2]
```
**Output**:
```
12.566370614359172
```
**Explanation**: Area of circle with r = 2 is pi * 2^2.

## Constraints

- ch is 1 or 2.

## Expected Complexity

Time: O(1)
Space: O(1)
