# What are Arrays and Strings

**Difficulty**: Easy

## Problem Statement

Understand the basic concepts and operations of 1D/2D Arrays and Strings in C++, Java, or Python.

Write a program that takes an integer `n` representing array size, followed by `n` integers for the array, and a string `s`. The program should print:
1. The first and last elements of the array.
2. The length and characters of string `s` in reverse order.

## Examples

### Example 1:

```
Input:
n = 5
arr = [10, 20, 30, 40, 50]
s = "hello"

Output:
First: 10, Last: 50
String Length: 5, Reversed: olleh
```

## Constraints

- `1 <= n <= 10^5`
- `-10^9 <= arr[i] <= 10^9`
- `1 <= s.length <= 10^5`
