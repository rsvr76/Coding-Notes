# Pattern Printing: Easy and Medium Logical Thinking

**Difficulty**: Easy

## Problem Statement

Given an integer `n`, print the fundamental right-angled triangle pattern of asterisks `*` of size `n`.

For `n = 4`, the output should be:
```
*
**
***
****
```

## Examples

### Example 1:

```
Input: n = 3
Output:
*
**
***
```

## Constraints

- `1 <= n <= 100`
