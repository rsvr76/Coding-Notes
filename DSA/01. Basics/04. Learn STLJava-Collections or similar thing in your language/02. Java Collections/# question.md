# Java Collections Framework Overview

**Difficulty**: Easy

## Problem Statement

Implement and demonstrate essential Java Collections Framework classes: `ArrayList`, `LinkedList`, `HashSet`, `TreeSet`, `HashMap`, `TreeMap`, `PriorityQueue`, and `Collections.sort()`.

Given `n` elements, insert them into an `ArrayList`, sort them, and map each unique element to its frequency using a `HashMap`.

## Examples

### Example 1:

```
Input: arr = [3, 1, 3, 2]
Output:
Sorted List: [1, 2, 3, 3]
Frequencies: {1=1, 2=1, 3=2}
```

## Constraints

- `1 <= n <= 10^5`
