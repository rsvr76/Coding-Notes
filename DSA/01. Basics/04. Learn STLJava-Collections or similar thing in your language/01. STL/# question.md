# C++ Standard Template Library (STL) Overview

**Difficulty**: Easy

## Problem Statement

Implement and demonstrate common C++ STL containers and algorithms: `std::vector`, `std::pair`, `std::set`, `std::map`, `std::unordered_map`, `std::stack`, `std::queue`, `std::priority_queue`, and `std::sort`.

Given `n` elements, insert them into a `std::vector`, sort them using `std::sort`, store frequencies in `std::map`, and output the sorted array and frequencies.

## Examples

### Example 1:

```
Input: arr = [4, 1, 2, 1, 4]
Output:
Sorted Vector: [1, 1, 2, 4, 4]
Frequencies: {1: 2, 2: 1, 4: 2}
```

## Constraints

- `1 <= n <= 10^5`
