# Union of Two Sorted Arrays

## Problem Statement

Given two sorted arrays `a` and `b`, find the union of two arrays containing distinct elements in sorted order.

## Input

Two sorted arrays `a` and `b`.

## Output

Sorted list of distinct elements present in either array.

## Examples

### Example 1

**Input**:
```
a = [1, 2, 3, 4, 5], b = [2, 3, 4, 4, 5, 6]
```
**Output**:
```
[1, 2, 3, 4, 5, 6]
```
**Explanation**: Distinct elements in both arrays.

## Constraints

- 1 <= N, M <= 10^5

## Expected Complexity

Time: O(N + M)
Space: O(N + M)
