# Longest Subarray with Sum K (Includes Negatives)

## Problem Statement

Given an array containing integers (positive, negative, zero) and a target sum `K`, find the length of the longest subarray with sum equal to `K`.

## Input

Array `arr` of integers, integer `K`.

## Output

Length of longest subarray.

## Examples

### Example 1

**Input**:
```
arr = [-1, 2, 3], K = 5
```
**Output**:
```
2
```
**Explanation**: Subarray [2, 3] has sum 5 and length 2.

## Constraints

- 1 <= N <= 10^5
- -10^9 <= arr[i] <= 10^9

## Expected Complexity

Time: O(N)
Space: O(N) hashing
