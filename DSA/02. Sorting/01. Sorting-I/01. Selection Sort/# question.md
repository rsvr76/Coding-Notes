# Selection Sort

**Difficulty**: Easy

## Problem Statement

Given an array `arr` of `N` integers, sort the array in non-decreasing order using the **Selection Sort** algorithm.

## Input

An integer `N` and an array `arr` of `N` integers.

## Output

Return or print the sorted array `arr`.

## Examples

### Example 1

**Input**: `N = 6, arr = [13, 46, 24, 52, 20, 9]`  
**Output**: `[9, 13, 20, 24, 46, 52]`

## Constraints

- `1 <= N <= 10^3`
- `-10^5 <= arr[i] <= 10^5`

## Expected Complexity

Time: O(N^2) in all cases
Space: O(1) auxiliary
