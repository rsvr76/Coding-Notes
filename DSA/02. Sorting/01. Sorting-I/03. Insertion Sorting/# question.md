# Insertion Sort

**Difficulty**: Easy

## Problem Statement

Given an array `arr` of `n` integers, sort the array using the **Insertion Sort** algorithm in non-decreasing order.

## Examples

### Example 1:
```
Input: n = 6, arr = [13, 46, 24, 52, 20, 9]
Output: [9, 13, 20, 24, 46, 52]
```

### Example 2:
```
Input: n = 5, arr = [5, 4, 3, 2, 1]
Output: [1, 2, 3, 4, 5]
```

## Constraints

- `1 <= n <= 10^3`
- `-10^4 <= arr[i] <= 10^4`
