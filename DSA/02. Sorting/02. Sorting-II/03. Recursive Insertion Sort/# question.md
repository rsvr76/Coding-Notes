# Recursive Insertion Sort Algorithm

## Problem Statement

Given an array of `N` integers, sort the array in non-decreasing order using **Recursive Insertion Sort**.

## Input

An integer `N` and array `arr`.

## Output

Sorted array.

## Examples

### Example 1

**Input**:
```
N = 5, arr = [13, 46, 24, 52, 20]
```
**Output**:
```
[13, 20, 24, 46, 52]
```
**Explanation**: Inserting elements recursively.

## Constraints

- 1 <= N <= 10^3

## Expected Complexity

Time: O(N^2)
Space: O(N) recursion stack
