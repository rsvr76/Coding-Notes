# Merge Sort

**Difficulty**: Medium

## Problem Statement

Given an array `arr` of `n` integers, sort the array using the **Merge Sort** algorithm in non-decreasing order.

## Examples

### Example 1:
```
Input: n = 5, arr = [4, 1, 3, 9, 7]
Output: [1, 3, 4, 7, 9]
```

### Example 2:
```
Input: n = 5, arr = [10, 9, 8, 7, 6]
Output: [6, 7, 8, 9, 10]
```

## Constraints

- `1 <= n <= 10^5`
- `-10^5 <= arr[i] <= 10^5`
