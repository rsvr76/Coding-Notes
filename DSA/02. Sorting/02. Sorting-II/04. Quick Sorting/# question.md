# Quick Sort

**Difficulty**: Medium

## Problem Statement

Given an array `arr` of `n` integers, sort the array using the **Quick Sort** algorithm in non-decreasing order.

## Examples

### Example 1:
```
Input: n = 8, arr = [4, 6, 2, 5, 7, 9, 1, 3]
Output: [1, 2, 3, 4, 5, 6, 7, 9]
```

### Example 2:
```
Input: n = 5, arr = [5, 4, 3, 2, 1]
Output: [1, 2, 3, 4, 5]
```

## Constraints

- `1 <= n <= 10^5`
- `-10^5 <= arr[i] <= 10^5`
