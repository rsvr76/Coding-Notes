# Minimum Cost to Connect Sticks / Ropes

**Difficulty**: Medium

## Problem Statement

You have `N` sticks with different lengths. You can connect any two sticks of lengths `X` and `Y` with cost `X + Y`. Return the minimum total cost to connect all sticks into one.

## Examples

### Example 1:
```
Input: sticks = [2, 4, 3]
Output: 14
Explanation: Connect 2+3=5 (cost 5), then 5+4=9 (cost 9). Total = 14.
```

## Constraints

- `1 <= N <= 10^4`
