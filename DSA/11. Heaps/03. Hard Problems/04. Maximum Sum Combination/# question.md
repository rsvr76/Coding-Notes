# Maximum Sum Combinations

**Difficulty**: Medium

## Problem Statement

Given two integer arrays `A` and `B` of size `N` each and an integer `K`, find `K` maximum possible sum combinations `A[i] + B[j]` in non-increasing order.

## Examples

### Example 1:
```
Input: A = [3, 2], B = [1, 4], K = 2
Output: [7, 6]
```

## Constraints

- `1 <= N, K <= 10^5`
