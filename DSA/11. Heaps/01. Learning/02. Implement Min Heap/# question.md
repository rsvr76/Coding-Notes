# Implement Min-Heap

**Difficulty**: Easy

## Problem Statement

Implement a **Min-Heap** data structure supporting `insert()`, `extractMin()`, and `getMin()` in $O(\log N)$ time using array representation.

## Examples

### Example 1:
```
Input: insert(4), insert(2), insert(8), getMin()
Output: getMin() returns 2
```

## Constraints

- `1 <= queries <= 10^5`
