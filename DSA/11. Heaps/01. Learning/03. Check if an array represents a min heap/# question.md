# Check if Array Represents a Min-Heap

**Difficulty**: Easy

## Problem Statement

Given an array `arr` of size `N`, return `true` if the array represents a valid **Min-Heap** (i.e. `arr[i] <= arr[2*i+1]` and `arr[i] <= arr[2*i+2]`), otherwise `false`.

## Examples

### Example 1:
```
Input: arr = [10, 15, 14, 25, 30]
Output: true
```

## Constraints

- `1 <= N <= 10^5`
