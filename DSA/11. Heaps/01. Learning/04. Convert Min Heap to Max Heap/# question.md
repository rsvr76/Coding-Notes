# Convert Min-Heap to Max-Heap

**Difficulty**: Medium

## Problem Statement

Given an array representing a valid **Min-Heap**, convert it in-place to a valid **Max-Heap** in $O(N)$ time.

## Examples

### Example 1:
```
Input: arr = [3, 5, 9, 6, 8, 20]
Output: [20, 8, 9, 6, 5, 3]
```

## Constraints

- `1 <= N <= 10^5`
