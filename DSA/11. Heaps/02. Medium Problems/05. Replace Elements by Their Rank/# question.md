# Replace Elements of Array by Their Rank

**Difficulty**: Easy

## Problem Statement

Given an array of `N` integers, replace each element with its rank in sorted order (smallest element rank 1). Equal elements get equal rank.

## Examples

### Example 1:
```
Input: arr = [20, 15, 26, 2, 98, 6]
Output: [4, 3, 5, 1, 6, 2]
```

## Constraints

- `1 <= N <= 10^5`
