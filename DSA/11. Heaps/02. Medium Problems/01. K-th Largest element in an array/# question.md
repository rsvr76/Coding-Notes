# K-th Largest element in an array

**Difficulty**: Medium

## Problem Statement

Given an array `arr` of `N` integers, find the largest element in the array.

## Input

An integer `N` and an array `arr` of `N` integers.

## Output

Return the largest element in `arr`.

## Examples

### Example 1

**Input**: `N = 5, arr = [2, 5, 1, 3, 0]`
**Output**: `5`

## Constraints

- `1 <= N <= 10^5`
- `-10^9 <= arr[i] <= 10^9`

## Expected Complexity

Time: O(N)
Space: O(1)
