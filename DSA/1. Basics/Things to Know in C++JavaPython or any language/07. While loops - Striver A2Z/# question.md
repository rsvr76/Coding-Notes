# While Loop - Sum of Even & Odd Digits

## Problem Statement

Given an integer `N`, find the sum of all its even digits and sum of all its odd digits separately.

## Input

An integer `N`.

## Output

Print even digit sum followed by odd digit sum.

## Examples

### Example 1

**Input**:
```
N = 12345
```
**Output**:
```
6 9
```
**Explanation**: Even digits (2,4) sum=6; Odd digits (1,3,5) sum=9.

## Constraints

- 0 <= N <= 10^9

## Expected Complexity

Time: O(log10 N)
Space: O(1)
