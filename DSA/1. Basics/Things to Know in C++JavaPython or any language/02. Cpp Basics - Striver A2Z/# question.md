# Data Types and Variable Declarations

## Problem Statement

Given a data type name as a string ('Integer', 'Long', 'Float', 'Double', 'Character'), return its size in bytes.

## Input

A string `type` representing the data type.

## Output

An integer representing the size in bytes.

## Examples

### Example 1

**Input**:
```
type = 'Integer'
```
**Output**:
```
4
```
**Explanation**: In C++/Java, Integer occupies 4 bytes.

## Constraints

- type is one of Integer, Long, Float, Double, Character.

## Expected Complexity

Time: O(1)
Space: O(1)
