# Input Output in C++/Java/Python

## Problem Statement

Write a program that reads a character or number from standard input and prints a message based on the input.

## Input

A single character or integer.

## Output

Print `1` if the character is uppercase ('A'-'Z'), `0` if lowercase ('a'-'z'), and `-1` if not an alphabetic character.

## Examples

### Example 1

**Input**:
```
A
```
**Output**:
```
1
```
**Explanation**: 'A' is an uppercase alphabet.

## Constraints

- Input is a single ASCII character.

## Expected Complexity

Time: O(1)
Space: O(1)
