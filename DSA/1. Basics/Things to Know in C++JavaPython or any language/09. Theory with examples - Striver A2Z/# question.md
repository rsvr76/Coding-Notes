# Time and Space Complexity Basics

## Problem Statement

Analyze time and space complexity of loops, nested loops, recursive functions, and auxiliary memory.

## Input

Code snippet / algorithm description.

## Output

Big-O notation representation.

## Examples

### Example 1

**Input**:
```
Single loop running N times
```
**Output**:
```
Time: O(N), Space: O(1)
```

## Constraints

- Conceptual overview.

## Expected Complexity

Time: O(1)
Space: O(1)
