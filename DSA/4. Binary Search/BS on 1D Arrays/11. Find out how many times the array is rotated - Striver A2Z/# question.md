# Find Rotation Count in Rotated Sorted Array

## Problem Statement

Given an array of `N` distinct integers rotated some number of times, find the number of times it has been rotated.

## Input

Rotated sorted array `arr`.

## Output

An integer representing rotation count (index of minimum element).

## Examples

### Example 1

**Input**:
```
arr = [5, 1, 2, 3, 4]
```
**Output**:
```
1
```
**Explanation**: Minimum element 1 is at index 1.

## Constraints

- 1 <= N <= 10^5

## Expected Complexity

Time: O(log N)
Space: O(1)
