# Square Root of an Integer (Floor Value)

## Problem Statement

Given a positive integer `N`, find the floor value of its square root using binary search.

## Input

An integer `N`.

## Output

`floor(sqrt(N))`.

## Examples

### Example 1

**Input**:
```
N = 7
```
**Output**:
```
2
```
**Explanation**: sqrt(7) = 2.6457..., floor is 2.

## Constraints

- 1 <= N <= 10^9

## Expected Complexity

Time: O(log N)
Space: O(1)
