# Fractional Knapsack Problem

**Difficulty**: Medium

## Problem Statement

Given weights and values of `N` items and a knapsack capacity `W`, find the maximum total value we can put in the knapsack. Items can be broken into fractions.

## Examples

### Example 1:
```
Input: N = 3, W = 50, values = [60, 100, 120], weights = [10, 20, 30]
Output: 240.00
```

## Constraints

- `1 <= N <= 10^5`
