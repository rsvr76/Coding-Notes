# Shortest Job First (SJF) CPU Scheduling

**Difficulty**: Medium

## Problem Statement

Given an array of execution times of `N` processes, find the average waiting time for all processes using **Shortest Job First (SJF)** non-preemptive scheduling.

## Examples

### Example 1:
```
Input: bt = [4, 3, 7, 1, 2]
Output: 4
```

## Constraints

- `1 <= N <= 10^5`
