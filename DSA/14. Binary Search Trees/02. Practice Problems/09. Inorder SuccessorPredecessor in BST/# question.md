# Inorder Successor / Predecessor in BST

**Difficulty**: Medium

## Problem Statement

Given a BST root and a target node `P`, find the **Inorder Successor** (smallest key `> P.val`) and **Inorder Predecessor** (largest key `< P.val`) of `P` in the BST.

## Examples

### Example 1:
```
Input: root = [20, 8, 22, 4, 12, null, null, null, null, 10, 14], P = 8
Output: Successor = 10, Predecessor = 4
```

## Constraints

- `1 <= number of nodes <= 10^5`
