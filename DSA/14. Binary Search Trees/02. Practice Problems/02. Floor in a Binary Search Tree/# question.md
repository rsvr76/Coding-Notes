# Floor in a Binary Search Tree

**Difficulty**: Medium

## Problem Statement

Given a BST root and a key `X`, find the **Floor** of `X` in the BST (largest element `<= X`). If no floor exists, return `-1`.

## Examples

### Example 1:
```
Input: root = [10, 5, 15, 2, 8, 12, 17], key = 7
Output: 5
```

## Constraints

- `1 <= number of nodes <= 10^5`
