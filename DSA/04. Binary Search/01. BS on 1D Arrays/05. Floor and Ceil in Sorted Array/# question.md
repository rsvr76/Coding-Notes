# Find Floor and Ceil in Sorted Array

## Problem Statement

Given a sorted array and `X`, find floor (largest element <= X) and ceil (smallest element >= X). Return -1 if not present.

## Input

Sorted array `arr`, integer `X`.

## Output

Pair `(floor, ceil)`.

## Examples

### Example 1

**Input**:
```
arr = [3, 4, 4, 7, 8, 10], X = 5
```
**Output**:
```
Floor = 4, Ceil = 7
```
**Explanation**: 4 <= 5 and 7 >= 5.

## Constraints

- 1 <= N <= 10^5

## Expected Complexity

Time: O(log N)
Space: O(1)
