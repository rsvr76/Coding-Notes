# Count Occurrences of X in Sorted Array

## Problem Statement

Given a sorted array `arr` of `N` integers and a target `X`, count the number of occurrences of `X` using binary search.

## Input

Sorted array `arr`, integer `X`.

## Output

Count of `X` in `arr`.

## Examples

### Example 1

**Input**:
```
arr = [1, 1, 2, 2, 2, 2, 3], X = 2
```
**Output**:
```
4
```
**Explanation**: 2 appears 4 times.

## Constraints

- 1 <= N <= 10^5

## Expected Complexity

Time: O(log N)
Space: O(1)
