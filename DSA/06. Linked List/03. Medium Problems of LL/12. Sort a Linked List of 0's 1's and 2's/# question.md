# Sort a Linked List of 0's, 1's and 2's

**Difficulty**: Medium

## Problem Statement

Given the head of a Singly Linked List containing values `0`, `1`, and `2`, sort the linked list by updating links so that all 0s appear first, followed by 1s, and then 2s.

## Examples

### Example 1:
```
Input: head = [1, 2, 2, 1, 2, 0, 2, 2]
Output: [0, 1, 1, 2, 2, 2, 2, 2]
```

## Constraints

- `1 <= number of nodes <= 10^5`
- `Node.val` ∈ `{0, 1, 2}`
