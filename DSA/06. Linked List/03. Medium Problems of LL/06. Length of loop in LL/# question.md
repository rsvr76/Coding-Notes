# Length of Loop in Linked List

**Difficulty**: Medium

## Problem Statement

Given the head of a linked list, determine whether the linked list contains a loop. If a loop is present, return the **number of nodes** involved in the loop. Otherwise, return `0`.

## Examples

### Example 1:

```
Input: head = 1 -> 2 -> 3 -> 4 -> 5 -> 3 (loop back to 3)
Output: 3
Explanation: The loop consists of nodes 3, 4, and 5. Length = 3.
```

## Constraints

- `1 <= Number of nodes <= 10^5`
- `-10^9 <= Node.val <= 10^9`
