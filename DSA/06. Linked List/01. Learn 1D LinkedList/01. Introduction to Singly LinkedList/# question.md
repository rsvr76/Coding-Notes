# Introduction to Singly LinkedList

**Difficulty**: Easy

## Problem Statement

Given an array of `n` integers, construct a **Singly Linked List** containing elements of the array in the same order and return the head of the linked list.

## Examples

### Example 1:

```
Input: arr = [1, 2, 3, 4, 5]
Output: 1 -> 2 -> 3 -> 4 -> 5
```

## Constraints

- `1 <= n <= 10^5`
- `-10^9 <= arr[i] <= 10^9`
