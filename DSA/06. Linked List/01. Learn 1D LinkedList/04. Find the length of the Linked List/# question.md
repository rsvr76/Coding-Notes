# Find the Length of Linked List

**Difficulty**: Easy

## Problem Statement

Given the head of a Singly Linked List, return the number of nodes present in the linked list.

## Examples

### Example 1:
```
Input: head = [1, 2, 3, 4, 5]
Output: 5
```

### Example 2:
```
Input: head = []
Output: 0
```

## Constraints

- `0 <= number of nodes <= 10^5`
