# Right/Left View of Binary Tree

**Difficulty**: Medium

## Problem Statement

Given the root of a Binary Tree, return the values of the nodes visible when viewed from the Right side (or Left side) ordered from top to bottom.

## Examples

### Example 1:
```
Input: root = [1, 2, 3, null, 5, null, 4]
Output (Right View): [1, 3, 4]
```

## Constraints

- `1 <= number of nodes <= 10^4`
