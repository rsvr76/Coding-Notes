# Top View of Binary Tree

**Difficulty**: Medium

## Problem Statement

Given the root of a Binary Tree, print the nodes that are visible when the tree is viewed from the top, ordered from leftmost horizontal distance to rightmost.

## Examples

### Example 1:
```
Input: root = [1, 2, 3, 4, 5, 6, 7]
Output: [4, 2, 1, 3, 7]
```

## Constraints

- `1 <= number of nodes <= 10^5`
