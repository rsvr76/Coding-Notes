# Boundary Traversal of Binary Tree

**Difficulty**: Medium

## Problem Statement

Given the root of a Binary Tree, return its boundary traversal in anti-clockwise order starting from root: Left boundary -> Leaf nodes -> Right boundary in reverse.

## Examples

### Example 1:
```
Input: root = [1, 2, 3, 4, 5, 6, 7]
Output: [1, 2, 4, 5, 6, 7, 3]
```

## Constraints

- `1 <= number of nodes <= 10^4`
