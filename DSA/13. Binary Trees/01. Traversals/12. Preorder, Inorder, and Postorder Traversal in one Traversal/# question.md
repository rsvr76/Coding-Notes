# Traversals

**Difficulty**: Medium

## Problem Statement

Given the root of a Binary Tree / Binary Search Tree, perform the **Traversals** operation as specified.

## Examples

### Example 1:
```
Input: root = [1, null, 2, 3]
Output: Traversal / resulting tree node value list.
```

## Constraints

- `0 <= Number of nodes <= 10^4`
- `-10^4 <= Node.val <= 10^4`
