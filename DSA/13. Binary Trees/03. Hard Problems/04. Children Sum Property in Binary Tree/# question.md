# Children Sum Property in Binary Tree

**Difficulty**: Hard

## Problem Statement

Given the root of a Binary Tree, modify node values in-place so that every node satisfies the **Children Sum Property**: `node.val = node.left.val + node.right.val`. You can only increment node values.

## Examples

### Example 1:
```
Input: root = [50, 7, 2, 3, 5, 1, 30]
Output: Tree modified to satisfy Children Sum Property.
```

## Constraints

- `1 <= number of nodes <= 10^4`
