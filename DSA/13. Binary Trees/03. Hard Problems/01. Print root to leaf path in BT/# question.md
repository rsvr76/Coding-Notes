# Print Root to Leaf Paths in Binary Tree

**Difficulty**: Medium

## Problem Statement

Given the root of a Binary Tree, return all root-to-leaf paths as a list of strings/lists.

## Examples

### Example 1:
```
Input: root = [1, 2, 3, null, 5]
Output: ["1->2->5", "1->3"]
```

## Constraints

- `1 <= number of nodes <= 10^4`
