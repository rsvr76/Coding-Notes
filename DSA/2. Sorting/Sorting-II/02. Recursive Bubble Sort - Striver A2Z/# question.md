# Recursive Bubble Sort Algorithm

## Problem Statement

Given an array of `N` integers, sort the array in non-decreasing order using **Recursive Bubble Sort**.

## Input

An integer `N` and array `arr`.

## Output

Sorted array.

## Examples

### Example 1

**Input**:
```
N = 5, arr = [5, 4, 3, 2, 1]
```
**Output**:
```
[1, 2, 3, 4, 5]
```
**Explanation**: Bubbling max to end recursively.

## Constraints

- 1 <= N <= 10^3

## Expected Complexity

Time: O(N^2)
Space: O(N) recursion stack
